# 世界模型页效果稿最小 UI 对齐

## Goal

以 2026-09-29 世界模型 HTML 效果稿及其说明为视觉参考，让当前 Chat 的真实 World Model 更紧凑、清晰，并保留既有分析、集合维护和模块编辑能力。

## Background

- 2026-09-29 只读审计时 worktree 干净。`ui/world.js:871-1023` 将归档名单单独渲染在选择区之前，归档行显示时间；当前类型的“生殖机制”即使没有条目也显示“未知”，且位于四个类型模块之前。
- `ui/app.js:5073-5083` 已有归档开关和还原委托；`ui/app.js:5333-5337` 的 Escape 当前直接关闭整个面板。数据来自现有 Runtime World Model / meta，存储归属遵循 `.trellis/spec/domain/floor-state.md` 与 `.trellis/spec/domain/world-model.md`。
- 效果稿是静态视觉样例；其中的种族、类型、规则、分析反馈和“预览长内容”仅供演示。

## Requirements

- R1 世界模型页仅做局部 UI 对齐：归档入口放在“种族”标题右侧、图标式新增种族左侧；归档浮层只列名称和还原操作，不显示归档时间。入口及数量从现有 `worldModelMeta.archived_species` 投影，归档项不混入活动种族选择器。
- R2 归档浮层可由同一入口切换、点浮层外关闭、按 Escape 关闭。浮层打开且世界页可见时，第一次 Escape 只关闭浮层并保持 BioWeave 面板打开；浮层已关闭时，Escape 继续执行现有面板关闭行为。点击面板内其他操作不应被浮层关闭逻辑吞掉；点击遮罩仍遵循既有面板关闭契约。
- R3 当前生物类型的 `reproductive_mechanisms` 有条目时，在“生殖规则”之后显示“生殖机制”；无条目时完全省略。该模块和世界级“投影规则”均为只读投影，不增加编辑按钮、表单、保存入口或新的持久化状态。生殖机制仍展示现有 Runtime 字段，不裁掉规则引用和依据。
- R4 保留类型侧四个可编辑模块（生殖能力、生殖规则、生命周期、特殊规则）与世界侧三个可编辑模块（医疗与照护、特殊例外、尚未确定）。保留独立编辑／保存／取消、单模块编辑、原生能力三态、集合增改归档还原删除、Full/Patch 分析及忙碌状态。
- R5 视觉仅在世界页作用域调整：沿用当前面板宽度和主题 token；桌面详情／世界级规则约 6:4，平板及手机单列，手机种族卡仅局部横向滚动。说明和普通属性值使用弱化文字色；模块图标底座 26×26px、图形约 17px；世界级规则内容及左侧特殊规则内容使用 13px / 1.5 行高。世界侧“特殊例外”“尚未确定”“投影规则”长内容各自最多 180px 后在内容区滚动，标题保持在外；“医疗与照护”首列 92px、列距 5px。
- R6 页面仅消费真实 Runtime DTO 与 meta；保留现有 `data-bioweave-*` 钩子、按钮语义、动态种族／类型名称与顺序、空状态、HTML 转义、API/存储/事件契约。不得引入效果稿演示数据或“预览长内容”控件。
- R7 同步 `docs/ui-framework.config.json`、`docs/UI_FRAMEWORK.md`、`docs/UI_FRAMEWORK_EXAMPLE.html`、`docs/UI_FULL_REFERENCE.html` 与生产 UI 的结构、样式、钩子和三端规则。只更新世界模型相关部分。

## Acceptance Criteria

- AC1 含归档与空归档的页面，归档入口都位于种族标题操作区；展开项只有名称与还原按钮，数量与 Runtime meta 一致，归档时间不进入可见 UI。对应 R1。
- AC2 开启浮层后点外侧关闭；再次开启后按一次 Escape 只关闭浮层，再按一次关闭面板；面板内其他操作和遮罩原有行为仍有效。对应 R2。
- AC3 切换到机制非空的类型时，该只读模块紧接生殖规则；切到机制空的类型时模块消失，四个可编辑类型模块及三个可编辑世界模块仍可操作；投影规则保持只读。对应 R3-R4。
- AC4 在 Desktop ≥1200px、Tablet 768–1199px、Mobile ≤767px 检查布局、焦点／按钮可用性、长内容滚动和页面无横向溢出；对照效果稿的有机制／无机制、归档打开／关闭和长内容状态。对应 R5。
- AC5 使用真实 Runtime 模型验证动态种族／类型与归档还原；无模型、无类型、无机制及分析中状态不显示演示数据，所有既有动作钩子继续工作。对应 R4、R6。
- AC6 配置、规范、示例、完整参考和生产 UI 一致；`npm run check`、`git diff --check` 通过，并记录真实 SillyTavern 三端验收结果或未执行原因。对应 R7。

## Out of Scope

- World Model schema、AI/Prompt、Runtime 分析与 Floor 持久化、API、Worldbook、其它页面及其交互。
- 给生殖机制或投影规则增加编辑能力；把示例内容写入生产 UI；全量 UI 重做。
- Commit、push、PR 或发布。
