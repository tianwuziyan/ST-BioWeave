# Anima 预览交互研究

## 观察到的实现

Anima 的 `scripts/rag.js` 在点击“预览”时重新读取当前 Chat，调用实际检索构建函数，再把结果按 `text` / `context` 分块渲染。每个块都有 header 和隐藏 content，点击 header 展开或收起；空结果明确显示没有命中，而不是填充示例数据。它还提供一个全局日志弹窗，显示最近一次实际合并结果和正文。

## BioWeave 采用的部分

- 预览动作触发临时构建，而不是把结果保存成设置。
- 以角色卡、世界书、最近剧情、外部记忆分组。
- 每组可展开查看实际正文，空组显示清晰空态。
- 结构预览与原始结构化 JSON 共享同一份本次生成的 DTO。

## 明确不采用的部分

- 不复制 Anima 的 RAG、向量检索、BM25、数据库、日志持久化或注入链路。
- 不读取 Anima 私有 Store；BioWeave 只使用已经确认的公开 SillyTavern/插件接口。
- 不把“最后一次检索结果”缓存为 BioWeave 数据；刷新或重新打开时重新构建。
