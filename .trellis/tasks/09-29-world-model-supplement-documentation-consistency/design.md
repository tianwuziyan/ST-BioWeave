# Documentation Design

Normative source of truth remains `.trellis/spec/domain/world-model.md`. README、architecture/developer docs and current source comments may summarize it but must not define a competing contract. Historical task archives remain immutable for historical accuracy.

The pass uses classification before editing: CURRENT, HISTORICAL, STALE, AMBIGUOUS, or NEGATIVE REGRESSION ASSERTION. Only stale/ambiguous current descriptions are edited. Any DOC/CODE CONTRACT CONFLICT stops implementation.
